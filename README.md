# PPVT-R 그림어휘력검사

취학전 아동을 위한 20문항 그림어휘력 검사 프로토타입입니다.

## 구성
- 일상 사물, 동물과 자연, 행동과 상태, 개념과 장소 4개 범주, 각 5문항
- 각 문항 4지선다, 정답 1개와 오답 3개
- `img/` 폴더의 SVG를 상대 경로로 연결
- 그림 파일이 없으면 파일명을 보존한 텍스트 대체 화면 표시
- 총점수, 범주별 점수, 문항별 반응 시간 대시보드
- UTF-8 BOM CSV 내보내기

## 실행
정적 파일이므로 `index.html`을 브라우저에서 직접 열거나 로컬 정적 서버에서 실행하면 됩니다.

> 본 도구는 교육·연구용 프로토타입이며 표준화 검사 결과를 대체하지 않습니다.
